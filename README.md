# Python for Scripting & Automation

A personal learning journey focused on Python scripting, task automation, and building practical projects.

This repository documents my learning process, coding exercises, notes, and progress as I work toward developing the skills needed to build useful automation tools and real-world projects.

## 🎯 Goal

My goal is to learn Python with a practical focus on scripting and automation. I want to use my computer science background to develop useful tools, solve repetitive tasks, and eventually take on small real-world projects and freelance opportunities.

Rather than learning Python purely for theoretical knowledge, I aim to focus on the concepts and skills that can be applied directly to practical problems.

## 🗺️ Learning Roadmap

I divided my learning path into three main stages:

1. **Python Fundamentals** — Building a solid foundation in Python.
2. **Python for Automation** — Learning the tools and techniques needed to automate tasks and write practical scripts.
3. **Real-World Projects** — Applying what I learn by building useful projects and gradually developing a portfolio.

This roadmap helps me prioritize the most relevant topics and maintain a clear direction throughout the learning process.

## 📅 Learning Progress

### Week 1 — Defining the Goal and Planning the Roadmap

The first week was about choosing a direction and identifying a field that aligned with my computer science background.

I wanted to find a practical learning path that would allow me to acquire useful skills in a relatively short time, start building projects, and eventually explore opportunities to earn income, even if initially modest.

Python scripting and automation seemed like the right starting point.

After discussing my goals and requirements with ChatGPT, I developed a three-stage roadmap covering Python fundamentals, automation, and practical projects.

*More details about my research and the use of AI tools during this stage will be added later.*

### Weeks 2–3 — Getting Started with Python

I began learning Python fundamentals using Jadi's comprehensive Python course on Maktabkhooneh.

My initial learning process included:

- Taking handwritten notes in a notebook.
- Following along with the lessons and writing code on my computer.
- Practicing the concepts as they were introduced.
- Getting familiar with Anaconda and its development environments, particularly Jupyter Notebook and Spyder.
- Progressing through the introductory topics and reaching the beginning of object-oriented programming and classes.

Although this approach helped me establish a foundation, I felt that progressing exclusively through video lessons was too slow for my available study time.

Since I balance work and university, I needed a more time-efficient learning strategy.

### Week 4 — Improving the Learning Process

With limited time available outside work and university, I decided to incorporate AI tools into my learning workflow.

I revisited my roadmap and broke down the remaining Python fundamentals into smaller, more specific topics.

I then used Claude to explain the remaining concepts with examples and provide three comprehensive exercises to help me practice writing code and apply what I had learned.

To improve review and retention, I also organized the explanations and notes in NotebookLM. Using these materials as sources, I created concise, graph-based study notes that would make it easier to revisit concepts quickly when needed.

During this stage, I also decided to upload my coding exercises to GitHub.

This repository became a way to document my progress from the beginning of my learning journey, keep my exercises organized, and eventually showcase the projects I build along the way.
