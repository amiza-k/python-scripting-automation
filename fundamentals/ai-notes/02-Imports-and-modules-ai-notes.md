# مبحث ۲: Import و ماژول‌ها در پایتون

## ۱. مفهوم Module و کاربرد آن

ماژول (Module) فایلی با پسوند `.py` است که شامل کدهای پایتون می‌شود؛ مثل توابع، متغیرها و کلاس‌ها.

ماژول‌ها کمک می‌کنند کدها را تقسیم‌بندی کنیم، دوباره استفاده کنیم و پروژه را منظم‌تر نگه داریم.

مثلاً به‌جای نوشتن تمام کدهای یک پروژه در یک فایل، می‌توانیم توابع مربوط به فایل‌ها را در یک ماژول جدا قرار دهیم.

## ۲. روش‌های Import

### روش اول: `import`

ماژول را وارد می‌کنیم و با نام آن به امکاناتش دسترسی داریم.

```
import mathresult = math.sqrt(25)
```

خروجی:

```
5.0
```

### روش دوم: `from ... import ...`

فقط بخش موردنیاز را وارد می‌کنیم و بدون نام ماژول از آن استفاده می‌کنیم.

```
from math import sqrtresult = sqrt(25)
```

خروجی:

```
5.0
```

### روش سوم: `import ... as ...`

برای نام مستعار یا کوتاه‌تر استفاده می‌شود.

```
import datetime as dttoday = dt.date.today()
```

متغیر `today` تاریخ روز را نگه می‌دارد.

نکته: در پروژه‌های واقعی، معمولاً از نام‌های مستعار شناخته‌شده استفاده می‌کنیم؛ مثلاً `import numpy as np`.

## ۳. ماژول‌های داخلی Python (Standard Library)

پایتون مجموعه‌ای از ماژول‌های آماده دارد که بدون نصب جداگانه در دسترس‌اند. این مجموعه را Standard Library می‌نامیم.

ماژول‌های مهم برای اسکریپت‌نویسی و اتوماسیون:

os

تعامل با سیستم‌عامل و متغیرهای محیطی؛ برای کار با مسیرها معمولاً pathlib مناسب‌تر است.

sys

دسترسی به آرگومان‌های برنامه و اطلاعات مفسر پایتون.

pathlib

ساخت، بررسی و مدیریت مسیر فایل‌ها و پوشه‌ها.

json

خواندن و نوشتن داده‌های JSON.

shutil

کپی، انتقال و حذف فایل‌ها و پوشه‌ها.

subprocess

اجرای برنامه‌ها و دستورات خارجی.

datetime

کار با تاریخ، زمان و محاسبات زمانی.

### چند مثال کاربردی

`pathlib` — ساخت مسیر فایل

```
from pathlib import Pathfile_path = Path("data") / "report.txt"print(file_path)
```

خروجی در ویندوز:

```
data\report.txt
```

`json` — تبدیل داده به JSON

```
import jsondata = {"name": "Ali", "age": 25}text = json.dumps(data)
```

خروجی متغیر `text`:

```
{"name": "Ali", "age": 25}
```

`datetime` — دریافت تاریخ و زمان فعلی

```
from datetime import datetimenow = datetime.now()
```

متغیر `now` شامل تاریخ و زمان فعلی سیستم است.

`os` — دریافت نام پوشه فعلی

```
import osfolder = os.getcwd()
```

`sys` — دریافت آرگومان‌های خط فرمان

```
import sysarguments = sys.argv
```

`shutil` — کپی فایل

```
import shutilshutil.copy("source.txt", "backup.txt")
```

این دستور فایل مبدأ را در مسیر مقصد کپی می‌کند.

`subprocess` — اجرای برنامه خارجی

```
import subprocesssubprocess.run(["python", "--version"], check=True)
```

این مثال نسخه پایتون را با اجرای یک فرایند خارجی بررسی می‌کند. برای اجرای دستورات، ورودی‌های نامطمئن را مستقیماً به shell ارسال نکن.

## ۴. ساخت ماژول شخصی

فرض کن دو فایل داری:

```
project/
    main.py
    helpers.py
```

در فایل `helpers.py`:

```
def greet(name):    return f"Hello, {name}"
```

در فایل `main.py`:

```
import helpersmessage = helpers.greet("Ali")print(message)
```

خروجی:

```
Hello, Ali
```

برای این روش، معمولاً هر دو فایل باید در مسیر قابل‌دسترسی پایتون باشند.

## ۵. مفهوم Package

Package روشی برای سازمان‌دهی چند ماژول در یک ساختار پوشه‌ای است.

مثلاً:

```
project/
    main.py
    tools/
        __init__.py
        text.py
        files.py
```

حالا می‌توانیم تابعی را از ماژول `text.py` وارد کنیم:

```
from tools.text import clean_text
```

فایل `__init__.py` در Packageهای معمولی برای مشخص‌کردن و آماده‌سازی Package استفاده می‌شود؛ در ساختارهای مدرن پایتون، بعضی Packageها بدون آن هم امکان‌پذیرند.

## ۶. تفاوت ماژول داخلی و کتابخانه نصب‌شدنی

- ماژول داخلی: همراه پایتون ارائه می‌شود؛ مثل `json` و `datetime`.
- کتابخانه نصب‌شدنی: معمولاً از منابعی مانند PyPI نصب می‌شود؛ مثل `requests` برای درخواست‌های HTTP.

برای نصب کتابخانه، از `pip` استفاده می‌کنیم:

```
python -m pip install requests
```

سپس در کد:

```
import requests
```

دستور نصب را در ترمینال اجرا می‌کنیم، نه داخل فایل پایتون.

## ۷. Virtual Environment و `venv`

محیط مجازی فضایی جداگانه برای نصب کتابخانه‌های هر پروژه است. این کار از تداخل نسخه‌ها بین پروژه‌ها جلوگیری می‌کند.

ساخت محیط مجازی:

```
python -m venv .venv
```

فعال‌سازی در ویندوز:

```
.venv\Scripts\activate
```

فعال‌سازی در Linux و macOS:

```
source .venv/bin/activate
```

سپس کتابخانه را در همان محیط نصب می‌کنیم:

```
python -m pip install requests
```

برای خروج از محیط مجازی:

```
deactivate
```

نکته: معمولاً پوشه `.venv` را وارد Git نمی‌کنیم؛ وابستگی‌های پروژه را می‌توان در فایلی مثل `requirements.txt` ثبت کرد.

## ۸. کاربرد `if __name__ == "__main__":`

این شرط مشخص می‌کند کدی فقط هنگام اجرای مستقیم فایل اجرا شود، نه زمانی که فایل از ماژول دیگری Import شده است.

```
def greet():    print("Hello")if __name__ == "__main__":    greet()
```

اگر این فایل را مستقیم اجرا کنیم، تابع `greet()` اجرا می‌شود. اگر آن را در فایل دیگری Import کنیم، تابع تعریف می‌شود اما این بخش اجرا نخواهد شد.

این الگو برای جداکردن کد اصلی برنامه از توابع قابل‌استفاده مجدد بسیار کاربردی است.

## ۹. سه تمرین جامع

### تمرین ۱ — مدیریت فایل‌ها

برنامه‌ای بنویس که با استفاده از `pathlib` وجود یک فایل را بررسی کند، نام و پسوند آن را نمایش دهد و در صورت وجود، با `shutil` از آن نسخه پشتیبان بسازد. مسیر فایل را از کاربر بگیر.

مفاهیم: pathlib، shutil، import

### تمرین ۲ — ذخیره اطلاعات در JSON

یک ماژول به نام `user_tools.py` بساز که تابعی برای ذخیره اطلاعات کاربر در فایل JSON و تابعی برای خواندن آن داشته باشد. در فایل `main.py` از این توابع استفاده کن و خطاهای نبودن فایل یا JSON نامعتبر را مدیریت کن.

مفاهیم: ماژول شخصی، json، from import

### تمرین ۳ — ابزار خط فرمان

پروژه‌ای با ماژول‌های جداگانه بساز که نام یک فایل را از آرگومان خط فرمان دریافت کند، وجود آن را بررسی کند، تاریخ و زمان بررسی را ثبت کند و گزارشی در JSON ذخیره کند. برای اجرای مستقیم فایل اصلی از `if __name__ == "__main__":` استفاده کن و پروژه را در یک محیط مجازی راه‌اندازی کن.

مفاهیم: sys، pathlib، datetime، json، Package و venv

پیشنهاد من این است که ابتدا تمرین دوم را انجام بده؛ چون با ماژول‌سازی، Import و کار با JSON هم‌زمان آشنا می‌شوی.
