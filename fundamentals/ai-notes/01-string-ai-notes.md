# آموزش کامل و سریع String در پایتون

رشته‌ها (`String`) یکی از مهم‌ترین انواع داده در پایتون هستند. تقریباً هر جا با نام، رمز عبور، پیام، متن، ورودی کاربر یا فایل متنی سروکار داشته باشی، از رشته‌ها استفاده می‌کنی.

## ۱. تعریف String و روش‌های ساخت آن

رشته یا `str` نوعی داده برای نگهداری متن است. متن می‌تواند شامل حروف، اعداد، فاصله‌ها، علامت‌ها و حتی ایموجی باشد.

```
name = "Ali"city = 'Tehran'message = "Hello, Python!"number_text = "12345"print(type(name))         # <class 'str'>print(type(number_text))  # <class 'str'>
```

نکته مهم: `"12345"` رشته است، نه عدد؛ چون داخل کوتیشن قرار گرفته است.

### روش‌های تعریف رشته

```
a = "Hello"          # دابل کوتیشنb = 'Hello'          # سینگل کوتیشنc = "I'm learning Python"d = 'He said "Hello"'e = ""               # رشته خالیf = str(123)         # تبدیل عدد به رشته
```

می‌توانی از کوتیشن تکی یا دوتایی استفاده کنی؛ تفاوت مهمی در نتیجه ندارند. معمولاً از نوعی استفاده می‌کنیم که نوشتن متن را راحت‌تر کند.

رشته‌ها همچنین می‌توانند چندخطی باشند:

```
text = """HelloWelcome to PythonHave a nice day"""print(text)
```

خروجی:

```
Hello
Welcome to Python
Have a nice day
```

### ویژگی بسیار مهم: رشته‌ها تغییرناپذیرند (Immutable)

بعد از ساخته‌شدن یک رشته، نمی‌توانی یکی از کاراکترهای آن را مستقیماً تغییر دهی.

```
word = "Python"# word[0] = "J"  # خطا!
```

به‌جای تغییر مستقیم، باید رشته جدید بسازی:

```
word = "J" + word[1:]print(word)  # Jython
```

این ویژگی را در تمام کار با رشته‌ها به یاد داشته باش.

## ۲. Indexing؛ دسترسی به کاراکترها

هر کاراکتر رشته یک موقعیت یا `Index` دارد. در پایتون، شماره‌گذاری از صفر آغاز می‌شود.

```
word = "Python"
```

## P

0

## y

1

## t

2

## h

3

## o

4

## n

5

شماره‌های مثبت از سمت چپ و از صفر شروع می‌شوند.

```
word = "Python"print(word[0])   # Pprint(word[1])   # yprint(word[5])   # n
```

### ایندکس منفی

شماره‌های منفی از انتهای رشته شروع می‌شوند:

```
word = "Python"print(word[-1])  # n، آخرین کاراکترprint(word[-2])  # oprint(word[-6])  # P
```

نکته مهم: اگر ایندکس از محدوده رشته خارج شود، پایتون خطای `IndexError` می‌دهد.

```
word = "Python"# print(word[10])  # IndexError
```

## ۳. Slicing؛ بریدن بخشی از رشته

با `Slicing` می‌توانی بخشی از رشته را استخراج کنی.

ساختار کلی:

```
string[start:stop:step]
```

- `start`: موقعیت شروع؛ شامل نتیجه می‌شود.
- `stop`: موقعیت پایان؛ در نتیجه شامل نمی‌شود.
- `step`: تعداد گام‌ها؛ اختیاری است و مقدار پیش‌فرض آن `1` است.

```
word = "Python"print(word[0:2])   # Pyprint(word[2:5])   # thoprint(word[:4])    # Pythprint(word[2:])    # thonprint(word[:])     # Python
```

اگر شروع یا پایان را حذف کنی، پایتون از ابتدا یا تا انتهای رشته را در نظر می‌گیرد.

### گام و ایندکس منفی در Slicing

```
text = "abcdef"print(text[::2])    # aceprint(text[1::2])   # bdfprint(text[::-1])   # fedcbaprint(text[-3:])    # defprint(text[4:1:-1]) # edc
```

کاربرد مهم `[::-1]`، معکوس‌کردن ترتیب کاراکترهای رشته است.

تفاوت بسیار مهم:

```
text = "Python"print(text[1])     # y، یک کاراکترprint(text[1:2])   # y، یک رشته با یک کاراکتر
```

اگر محدوده Slice از طول رشته فراتر برود، برخلاف Indexing معمولاً خطا نمی‌گیری؛ پایتون تا حد ممکن بخش موجود را برمی‌گرداند.

```
print("Python"[2:100])  # thon
```

## ۴. متدهای پرکاربرد رشته‌ها

متد (`Method`) عملی است که روی یک مقدار انجام می‌دهیم. متدهای رشته معمولاً به این شکل فراخوانی می‌شوند:

```
text.method()
```

### `lower()` و `upper()`

تبدیل حروف انگلیسی به حروف کوچک یا بزرگ:

```
text = "Hello Python"print(text.lower())  # hello pythonprint(text.upper())  # HELLO PYTHON
```

این متدها رشته اصلی را تغییر نمی‌دهند؛ بلکه رشته جدیدی برمی‌گردانند.

```
text = "HELLO"text.lower()print(text)  # HELLO
```

اگر بخواهی مقدار جدید را ذخیره کنی:

```
text = text.lower()
```

### `strip()`

حذف فاصله‌ها و کاراکترهای سفید از ابتدای و انتهای رشته:

```
text = "   Python   "print(text.strip())   # "Python"print(text.lstrip())  # حذف از سمت چپprint(text.rstrip())  # حذف از سمت راست
```

`strip()` فاصله‌های وسط رشته را حذف نمی‌کند:

```
print("  Hello World  ".strip())# Hello World
```

### `replace()`

جایگزین‌کردن بخشی از رشته:

```
text = "I like Java"print(text.replace("Java", "Python"))# I like Python
```

می‌توانی تعداد جایگزینی‌ها را نیز مشخص کنی:

```
text = "apple apple apple"print(text.replace("apple", "orange", 2))# orange orange apple
```

### `split()`

تبدیل یک رشته به فهرستی (`list`) از رشته‌ها:

```
text = "Ali Sara Reza"print(text.split())# ['Ali', 'Sara', 'Reza']
```

بدون آرگومان، `split()` بر اساس فاصله‌های متوالی و سایر کاراکترهای سفید جدا می‌کند.

می‌توانی جداکننده مشخص کنی:

```
data = "Ali,20,Tehran"print(data.split(","))# ['Ali', '20', 'Tehran']
```

دقت کن که خروجی `split()` یک رشته نیست؛ یک لیست است.

### `join()`

عمل معکوسِ رایج `split()` است: چند رشته را با یک جداکننده به هم متصل می‌کند.

```
words = ["I", "love", "Python"]print(" ".join(words))# I love Pythonprint("-".join(words))# I-love-Python
```

ترتیب استفاده به این شکل است:

```
"جداکننده".join(لیست_رشته‌ها)
```

تمام اعضای ورودی `join()` باید رشته باشند:

```
numbers = ["10", "20", "30"]print(",".join(numbers))  # 10,20,30
```

اما این کد خطا می‌دهد:

```
# ",".join(["10", 20, "30"])  # TypeError
```

چون عدد `20` از نوع رشته نیست.

## ۵. جست‌وجو و بررسی متن

### `find()`

موقعیت اولین رخداد یک زیررشته را پیدا می‌کند:

```
text = "I love Python"print(text.find("love"))    # 2print(text.find("Python"))  # 7print(text.find("Java"))    # -1
```

اگر عبارت پیدا نشود، `find()` مقدار `-1` برمی‌گرداند؛ خطا نمی‌دهد.

می‌توانی محدوده جست‌وجو را نیز مشخص کنی:

```
text = "banana"print(text.find("a"))     # 1print(text.find("a", 2))  # 3
```

### عملگر `in`

بررسی می‌کند که آیا یک کاراکتر یا زیررشته در رشته وجود دارد یا خیر. نتیجه آن `True` یا `False` است.

```
text = "I love Python"print("Python" in text)  # Trueprint("Java" in text)    # Falseprint("P" in text)       # True
```

برای بررسی نبودن از `not in` استفاده کن:

```
print("Java" not in text)  # True
```

### `startswith()` و `endswith()`

بررسی می‌کنند که رشته با چه چیزی شروع یا تمام می‌شود:

```
filename = "report.pdf"print(filename.startswith("report"))  # Trueprint(filename.endswith(".pdf"))     # Trueprint(filename.endswith(".jpg"))     # False
```

این متدها نیز به بزرگی و کوچکی حروف حساس هستند:

```
print("Python".startswith("py"))  # False
```

برای بررسی بدون حساسیت به بزرگی و کوچکی حروف:

```
text = "Python"print(text.lower().startswith("py"))  # True
```

## ۶. متدهای بررسی نوع کاراکترها

این متدها به تو کمک می‌کنند محتوای یک رشته را بررسی کنی. خروجی همه آن‌ها `True` یا `False` است.

| متد         | کاربرد                              |
| ----------- | ----------------------------------- |
| `isdigit()` | آیا همه کاراکترها رقم هستند؟        |
| `isalpha()` | آیا همه کاراکترها حرف هستند؟        |
| `isalnum()` | آیا همه کاراکترها حرف یا رقم هستند؟ |

مثال‌ها:

```
print("12345".isdigit())     # Trueprint("Hello".isalpha())    # Trueprint("Hello123".isalnum()) # Trueprint("Hello World".isalpha())  # Falseprint("123 abc".isalnum())      # Falseprint("123.5".isdigit())        # False
```

چرا `"Hello World".isalpha()` مقدار `False` می‌دهد؟ چون رشته دارای فاصله است و فاصله حرف محسوب نمی‌شود.

نکته‌های مهم:

- رشته خالی `""` برای هر سه متد `False` برمی‌گرداند.
- علامت منفی و ممیز اعشاری جزو رقم نیستند؛ پس `"-12".isdigit()` و `"12.5".isdigit()` هر دو `False` هستند.
- `isalpha()` حروف فارسی را نیز حرف محسوب می‌کند:

```
print("سلام".isalpha())  # True
```

برای اعتبارسنجی عددهای اعشاری، صرفاً به `isdigit()` تکیه نکن؛ روش تبدیل عددی و مدیریت خطا مناسب‌تر است.

## ۷. اتصال رشته‌ها با عملگر `+`

با `+` می‌توانی دو یا چند رشته را به یکدیگر متصل کنی.

```
first_name = "Ali"last_name = "Ahmadi"full_name = first_name + " " + last_nameprint(full_name)  # Ali Ahmadi
```

اگر فاصله یا جداکننده را خودت اضافه نکنی، رشته‌ها بدون فاصله به هم متصل می‌شوند.

```
print("Hello" + "Python")  # HelloPython
```

### خطای رایج: اتصال رشته و عدد

```
age = 20# print("Age: " + age)  # TypeError
```

نمی‌توانی رشته و عدد را مستقیماً با `+` ترکیب کنی؛ ابتدا باید عدد را به رشته تبدیل کنی:

```
print("Age: " + str(age))  # Age: 20
```

برای بسیاری از موارد، استفاده از `f-string` خواناتر است که در بخش بعد می‌بینی.

## ۸. فرمت‌بندی با f-string

`f-string` یکی از بهترین و خواناترین روش‌ها برای قرار دادن مقدار متغیرها داخل متن است.

برای ساخت آن، حرف `f` را قبل از کوتیشن قرار می‌دهیم و متغیر را داخل آکولاد `{}` می‌نویسیم.

```
name = "Sara"age = 22message = f"My name is {name} and I am {age} years old."print(message)# My name is Sara and I am 22 years old.
```

مزیت آن این است که لازم نیست با `+` چند رشته را به هم متصل کنی یا متغیرها را دستی به رشته تبدیل کنی.

### محاسبه داخل f-string

```
a = 10b = 5print(f"Sum = {a + b}")  # Sum = 15
```

### قالب‌بندی عددها

```
price = 1234.5678print(f"{price:.2f}")  # 1234.57print(f"{price:.1f}")  # 1234.6
```

عدد `.2f` یعنی نمایش عدد اعشاری با دو رقم بعد از ممیز. مقدار اصلی متغیر تغییر نمی‌کند.

```
name = "Ali"print(f"Hello, {name.upper()}!")  # Hello, ALI!
```

داخل آکولادها می‌توانی یک عبارت یا فراخوانی متد نیز بنویسی.

اگر بخواهی خود آکولاد را به‌عنوان متن نمایش دهی، آن را دو بار بنویس:

```
name = "Ali"print(f"{{{name}}}")  # {Ali}
```

## ۹. Escape Characters

بعضی کاراکترها را نمی‌توانیم به‌شکل معمولی درون رشته نمایش دهیم یا می‌خواهیم معنای خاصی داشته باشند. برای این کار از بک‌اسلش `\` استفاده می‌کنیم.

| عبارت | معنی                 |
| ----- | -------------------- |
| `\n`  | رفتن به خط جدید      |
| `\t`  | ایجاد فاصله شبیه Tab |
| `\\`  | نمایش یک بک‌اسلش     |
| `\'`  | نمایش کوتیشن تکی     |
| `\"`  | نمایش کوتیشن دوتایی  |

مثال:

```
print("Hello\nWorld")
```

خروجی:

```
Hello
World
```

مثال Tab:

```
print("Name:\tAli")# Name:   Ali
```

مثال بک‌اسلش:

```
print("C:\\Users\\Ali")# C:\Users\Ali
```

### رشته خام (Raw String)

اگر بخواهی بک‌اسلش‌ها معمولاً به‌عنوان کاراکترهای Escape تفسیر نشوند، می‌توانی از `r` قبل از کوتیشن استفاده کنی.

```
path = r"C:\Users\Ali\Documents"print(path)
```

این قابلیت برای نوشتن بعضی مسیرهای فایل و الگوهای متنی مفید است. توجه کن که Raw String محدودیت‌هایی هم دارد؛ مثلاً نمی‌توان آن را با یک بک‌اسلش منفرد در انتها تعریف کرد.

## ۱۰. رشته‌های چندخطی

برای نوشتن رشته‌ای که در چند خط ادامه دارد، می‌توانی از سه کوتیشن تکی یا سه کوتیشن دوتایی استفاده کنی.

```
message = """Hello,Welcome to Python.Let's start coding."""print(message)
```

خروجی:

```
Hello,
Welcome to Python.
Let's start coding.
```

تفاوت مهم این روش با `\n` این است که در رشته‌های سه‌کوتیشنی، خط‌ها را مستقیماً در کد می‌نویسی.

یک نکته: فاصله‌ها و شکست خط‌هایی که در محتوای رشته قرار می‌دهی معمولاً حفظ می‌شوند. بنابراین تورفتگی ناخواسته در کد ممکن است داخل خروجی هم دیده شود.

همچنین می‌توانی در یک رشته معمولی از `\n` برای کنترل خط جدید استفاده کنی:

```
message = "Hello,\nWelcome to Python."print(message)
```

این دو روش برای بسیاری از کاربردها نتیجه مشابهی می‌دهند.

## ۱۱. تبدیل String به عدد و برعکس

وقتی از کاربر ورودی می‌گیری، باید یادت باشد که `input()` خروجی را به‌شکل رشته برمی‌گرداند؛ حتی اگر کاربر یک عدد وارد کند.

### `int()`؛ تبدیل به عدد صحیح

```
age_text = "25"age = int(age_text)print(age + 5)  # 30print(type(age))  # <class 'int'>
```

### `float()`؛ تبدیل به عدد اعشاری

```
price_text = "19.75"price = float(price_text)print(price + 1)  # 20.75
```

### `str()`؛ تبدیل به رشته

```
age = 25text = str(age)print(text + " years")  # 25 yearsprint(type(text))       # <class 'str'>
```

### تبدیل ورودی کاربر

```
age = int(input("Enter your age: "))height = float(input("Enter your height: "))print(f"Age: {age}")print(f"Height: {height}")
```

اگر کاربر در ورودی اول `25` وارد کند، مقدار `age` عدد صحیح ۲۵ خواهد بود؛ در ورودی دوم نیز `height` به عدد اعشاری تبدیل می‌شود.

### تبدیل نامعتبر و خطای `ValueError`

هر رشته‌ای قابل تبدیل به عدد نیست:

```
# int("hello")  # ValueError# int("12.5")   # ValueError
```

برای تبدیل رشته `"12.5"` به عدد اعشاری می‌توانی از این روش استفاده کنی:

```
number = float("12.5")print(number)  # 12.5
```

اگر ورودی کاربر قابل پیش‌بینی نباشد، می‌توانی خطا را مدیریت کنی:

```
text = input("Enter a number: ")try:    number = float(text)    print(number * 2)except ValueError:    print("Please enter a valid number.")
```

این کد هنگام واردشدن یک عدد معتبر، آن را پردازش می‌کند و هنگام ورودی نامعتبر، پیام مناسبی نمایش می‌دهد.

| `text[::-1]`                          | برعکس‌کردن ترتیب رشته                            |
| `lower()` و `upper()`                 | تغییر بزرگی و کوچکی حروف انگلیسی                 |
| `strip()`                             | حذف فاصله‌های ابتدا و انتها                      |
| `replace()`                           | جایگزینی بخشی از متن                             |
| `split()`                             | تبدیل رشته به لیست                               |
| `join()`                              | اتصال رشته‌های یک مجموعه با جداکننده             |
| `find()`                              | یافتن موقعیت؛ در صورت عدم یافتن `-1`             |
| `in`                                  | بررسی وجود یک زیررشته                            |
| `startswith()` و `endswith()`         | بررسی ابتدا و انتهای رشته                        |
| `isdigit()`، `isalpha()`، `isalnum()` | بررسی محتوای رشته                                |
| `+`                                   | اتصال رشته‌ها؛ نه رشته و عدد به‌صورت مستقیم      |
| `f-string`                            | جای‌گذاری متغیرها و عبارت‌ها در متن              |
| `\n` و `\t`                           | خط جدید و Tab                                    |
| `int()`، `float()`، `str()`           | تبدیل نوع داده                                   |

# ۱۳. سه تمرین جامع برای کدنویسی

## تمرین ۱: تحلیل و پاک‌سازی متن

سطح: مقدماتی تا متوسط

برنامه‌ای بنویس که یک متن از کاربر دریافت کند و اطلاعات زیر را نمایش دهد:

- متن را از فاصله‌های اضافی ابتدا و انتها پاک کند.
- متن پاک‌شده را به حروف کوچک و سپس حروف بزرگ تبدیل کند.
- تعداد کاراکترهای متن پاک‌شده را محاسبه کند.
- اولین و آخرین کاراکتر را نمایش دهد؛ اگر متن خالی است، خطا ندهد.
- بررسی کند که آیا کلمه `"python"` در متن وجود دارد یا نه؛ بررسی باید نسبت به بزرگی و کوچکی حروف حساس نباشد.
- تعداد کلمات را با استفاده از `split()` محاسبه کند.
- متن را با استفاده از `replace()` تغییر دهد و نتیجه جدید را نشان دهد.
- متن را از انتها به ابتدا نمایش دهد.

ورودی آزمایشی: `   I Love Python Programming   `

برای تعداد کلمات و معکوس‌کردن رشته از متدها و عملیات مناسب استفاده کن، نه اینکه نتیجه را دستی بنویسی.

## تمرین ۲: تحلیل اطلاعات کاربر

سطح: متوسط

برنامه‌ای بنویس که نام، سن و قیمت محصول را از کاربر دریافت کند و گزارش مناسبی بسازد.

شرایط برنامه:

- نام کاربر ممکن است ابتدا یا انتهایش فاصله اضافی داشته باشد؛ آن را پاک‌سازی کن.
- سن باید از رشته به عدد صحیح تبدیل شود.
- قیمت باید به عدد اعشاری تبدیل شود.
- اگر سن یا قیمت ورودی نامعتبر بود، خطای تبدیل را مدیریت کن.
- نام را به‌شکل مناسب در گزارش نمایش بده و تعداد کاراکترهای نام را محاسبه کن.
- قیمت را با دو رقم اعشار نمایش بده.
- با استفاده از `f-string` گزارشی چندخطی بساز.
- بررسی کن آیا نام فقط شامل حروف است یا نه. در نظر بگیر که نام دارای فاصله ممکن است `isalpha()` را `False` کند.
- در پایان، سن کاربر را پنج سال افزایش بده و در گزارش نمایش بده.

نمونه ورودی:

```
Name:   Sara
Age: 22
Price: 149.5
```

نمونه بخشی از خروجی مورد انتظار:

```
User: Sara
Age: 22
Age after 5 years: 27
Price: 149.50
```

مدیریت ورودی‌های نامعتبر باید بخشی از برنامه باشد؛ یعنی ورودی اشتباه نباید باعث بسته‌شدن ناگهانی برنامه شود.

## تمرین ۳: اعتبارسنجی و پردازش نام کاربری

سطح: متوسط تا چالشی

برنامه‌ای برای بررسی نام کاربری و تولید یک گزارش متنی بنویس.

قانون‌های نام کاربری:

- فاصله‌های ابتدا و انتهای ورودی باید حذف شوند.
- طول نام کاربری باید بین ۵ تا ۱۵ کاراکتر باشد.
- نام کاربری باید فقط از حروف انگلیسی و اعداد تشکیل شود؛ از `isalnum()` استفاده کن، اما به‌تنهایی به آن اکتفا نکن.
- نام کاربری باید با یک حرف شروع شود.
- بررسی شروع نام کاربری باید نسبت به حروف کوچک و بزرگ مشکلی نداشته باشد.
- در صورت معتبر بودن، نام کاربری را به حروف کوچک تبدیل کن.
- تعداد حروف و ارقام را جداگانه محاسبه کن.
- بررسی کن که آیا نام کاربری با `"admin"` شروع می‌شود یا نه.
- یک گزارش چندخطی با `f-string` تولید کن.
- در گزارش، نام کاربری اصلی، نام کاربری استانداردشده، طول نام کاربری، تعداد حروف و ارقام و نتیجه اعتبارسنجی را نمایش بده.
